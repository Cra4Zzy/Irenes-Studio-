## Bildmaterial
Für die Demo werden die öffentlich erreichbaren Bild-URLs der bestehenden Webador-Seite verwendet. Vor einem echten Launch sollten die Originalbilder direkt von Irene übernommen, lokal gespeichert und für WebP/AVIF optimiert werden. Das verhindert Fremdabhängigkeiten und verbessert Performance, Datenschutz und Bildqualität.
